## Site oficial

O site da Atletis é **[atletis.com.br](https://www.atletis.com.br)**.

| O que | Link |
|---|---|
| Site oficial | https://www.atletis.com.br |
| Calendário de eventos com inscrições abertas | https://www.atletis.com.br/eventos |
| Página para organizadores (criar evento) | https://www.atletis.com.br/criar-evento-esportivo |
| Dúvidas frequentes | https://www.atletis.com.br/duvidas-frequentes |
| Blog | https://www.atletis.com.br/blog |
| Termos de uso | https://www.atletis.com.br/termos-de-uso |
| Política de privacidade | https://www.atletis.com.br/politica-de-privacidade |

A página de cada evento segue o padrão `https://www.atletis.com.br/evento/nome-do-evento`.
